# Audit — 2026-09-20 — Frontend F3.3 Shop filters, card ratings & compare

**Task:** `plan/frontend-tasks.md` → Milestone F3 §F3.3 — move shop filtering and
sorting to the server, add availability/tag/badge/on-sale chips, show ratings on
`ProductCard`, and add an add-to-compare toggle plus a `/compare` page.

Pre-flight: `GET /products` already accepted
`category, tag, badge, availability, on_sale, size, color, min_price, max_price,
sort` (`new|popular|rating|price_asc|price_desc`) and F3.0 had wrapped them in
`api.products()`; `GET /products/compare?ids=` was live and smoke-verified.
`DESIGN_SYSTEM.md` was read first (Persian/RTL, `@/`, `cn()`, brand tokens, `toFa`,
TanStack Query, `sonner`, existing `ui/*` primitives — `Table`, `Slider`, `Button`).

## What is NOT done / open

- **Single-value `size`/`color`.** The backend takes one size and one colour, so
  the multi-select sidebar became single-select (toggling a chip off clears it).
  Logged as **B4.12** (accept repeated/comma-separated values) — multi-select in
  the UI has to wait for that.
- **Tag chips are derived from the cached catalog** (`useCatalog()`), not a
  dedicated facet endpoint, so they list every tag in the store and ignore the
  current category/filters. A `/products/facets`-style endpoint would be better
  (not scheduled).
- `?q=` search results still render without the filter sidebar (F3.1 left it that
  way; the two views are now more different than before — worth unifying when the
  backend search gains filters).
- **No pagination** — `GET /products` returns everything (F2.5).
- The compare set is **client-side only** (localStorage), capped at 4 by the UI
  while the backend accepts 10; there is no per-customer server-side compare list.
- Compare page shows **product-level** stock/availability, not per-variant
  availability (the endpoint does not return variants).
- The `react-refresh/only-export-components` warning on `lib/compare.tsx` is the
  same pre-existing pattern as `lib/cart.tsx`/`lib/auth.tsx` (provider + hook in
  one file) and was left alone deliberately.
- Docs deliberately untouched: `vogue-vintage-vibes/README.md` (no setup/stack
  change), `backend/README.md` and `infra/README.md` (no backend/infra change),
  `plan/RULES.md`.
