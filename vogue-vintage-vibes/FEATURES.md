# فهرست کامل امکانات پروژه (Feature List)

پروژه: فروشگاه آنلاین پوشاک زنانه «ساندِه» (SÂNDÉ)

## ۵. بک‌اند (Supabase)

- **جداول**: `profiles`، `user_roles`، `products`، `addresses`، `favorites`، `orders`، `order_items`، `payments`، `refund_requests`
- **RLS** روی همه جداول + پالیسی‌های مالکیت/ادمین
- **تریگرها**: ساخت خودکار پروفایل+نقش customer هنگام ثبت‌نام، `updated_at` خودکار
- **Storage**: bucket `product-images` با پالیسی‌های خواندن عمومی/نوشتن ادمین
- **شماره سفارش** خودکار (`order_number`) + کد پیگیری `SND-...`
- **Server Functions** (TanStack Start): `getPaymentSession`، `completePayment`، `cancelOrder`، `requestRefund`، `resolveRefundRequest` — همه با اعتبارسنجی Zod و middleware احراز هویت
- **دیتای اولیه (seed)**: ۲۰ محصول در ۵ دسته

## ۷. آنچه با پایتون می‌توان تکمیل کرد (پیشنهاد)

پایتون می‌تواند به‌عنوان **لایه‌ی سرویس کنار Supabase** (نه جایگزین فرانت) اضافه شود:

1. **FastAPI Backend Service** — API برای قابلیت‌هایی که Supabase سخت انجام می‌دهد
2. **درگاه پرداخت واقعی** — اتصال به زرین‌پال / آیدی‌پی / زیبال (request + verify + callback)
3. **سیستم کد تخفیف واقعی** — جدول کوپن، اعتبارسنجی، سقف مصرف، درصد/مبلغ ثابت، تاریخ انقضا
4. **اعلان پیامک/ایمیل** — کاوه‌نگار / ملی‌پیامک / SMTP برای ثبت سفارش، ارسال، لغو، بازپرداخت
5. **کسر موجودی تراکنشی** — با رعایت concurrency هنگام ثبت سفارش
6. **جستجوی محصولات** — جستجوی متنی + پیشنهاد (یا حتی pgroonga/Elastic)
7. **موتور توصیه‌گر (Recommendation)** — محصولات مرتبط هوشمند بر اساس خرید کاربران
8. **گزارش‌سازی و نمودار** — فروش روزانه/ماهانه، پرفروش‌ها، خروجی Excel (openpyxl/pandas)
9. **ریسپانسیو وب‌هوک‌ها** — اطلاع‌رسانی رویدادها (order placed, paid, shipped)
10. **اتوماسیون پس‌زمینه** — تسک‌های زمان‌بندی‌شده (به‌روزرسانی وضعیت مرسوله، یادآوری پرداخت سفارش‌های رهاشده)
11. **فاکتور PDF** — تولید فاکتور سفارش با reportlab/weasyprint
12. **درون‌ریزی/برون‌بری محصولات** — ابزار CLI یا ادمین برای import/export CSV محصولات
