# فهرست کامل امکانات پروژه (Feature List)

پروژه: فروشگاه آنلاین پوشاک زنانه «ساندِه» (SÂNDÉ)
استک فعلی: TanStack Start (React 19) + TypeScript + Tailwind CSS 4 + shadcn/ui + TanStack Query + Vite — و بک‌اند اختصاصی **FastAPI** (`../backend`) با PostgreSQL و MinIO. دیگر Supabase وجود ندارد.

## ۵. بک‌اند (FastAPI اختصاصی — بدون Supabase)

- **احراز هویت**: JWT خودِ سرویس (HS256) + رمزهای bcrypt در `public.users`؛ نقش‌ها از `public.user_roles`
- **جداول**: `users`، `profiles`، `user_roles`، `products`، `product_variants`، `product_reviews`، `search_history`، `recently_viewed`، `addresses`، `favorites`، `orders`، `order_items`، `payments` (ستون `authority`)، `refund_requests`، `coupons`، `coupon_redemptions`، `contact_messages`، `notifications`، `notification_deliveries` (صف ارسال پیامک/ایمیل)، `notification_settings`
- **Storage**: MinIO با bucket `product-images` و لینک‌های امضاشده (`/storage/upload-url`، `/storage/sign`)
- **شماره سفارش** خودکار (`order_number`) + کد پیگیری `SND-...`
- **کسر موجودی تراکنشی** با `FOR UPDATE` و کاهش variant-aware — بدون oversell
- **گیت وضعیت عرضه** (`availability`): `coming_soon`/`preorder` در `POST /stock/check` و `checkout` با دلیل `not_available` رد می‌شوند (پیش‌خرید فعلاً قابل سفارش نیست — B4.13)
- **Schema افزودنی**: جداول/ستون‌های کوپن و کاتالوگ به‌صورت idempotent در استارتاپ ساخته می‌شوند (`app/db.py`)
- **جستجو**: تطبیق ILIKE روی نام، توضیحات، جنس، دسته و آرایهٔ `tags`، با رتبه‌بندی نام > دسته > برچسب > توضیحات (`app/services/search.py`)
- **دیتای اولیه (seed)**: `seed_auth` (ادمین + مشتری)، `seed_products` (۲۰ محصول با برچسب‌های جستجو: پنبه، کتان، دنیم، تابستانی و …)، `seed_demo`، `seed_coupons`
- **مستندات API**: http://localhost:8000/docs — جزئیات در `../backend/README.md`

## ۷. آنچه با پایتون می‌توان تکمیل کرد (پیشنهاد)

پایتون می‌تواند به‌عنوان **لایه‌ی سرویس کنار Supabase** (نه جایگزین فرانت) اضافه شود:

1. **FastAPI Backend Service** — API برای قابلیت‌هایی که Supabase سخت انجام می‌دهد
2. **درگاه پرداخت واقعی** — اتصال به زرین‌پال / آیدی‌پی / زیبال (request + verify + callback)
3. **سیستم کد تخفیف واقعی** — جدول کوپن، اعتبارسنجی، سقف مصرف، درصد/مبلغ ثابت، تاریخ انقضا
4. **اعلان پیامک/ایمیل** — کاوه‌نگار / ملی‌پیامک / SMTP برای ثبت سفارش، ارسال، لغو، بازپرداخت
5. **کسر موجودی تراکنشی** — با رعایت concurrency هنگام ثبت سفارش
6. **جستجوی محصولات** — جستجوی متنی + پیشنهاد (یا حتی pgroonga/Elastic)
7. **موتور توصیه‌گر (Recommendation)** — محصولات مرتبط هوشمند بر اساس خرید کاربران
8. **گزارش‌سازی و نمودار** — فروش روزانه/ماهانه، پرفروش‌ها، خروجی Excel (openpyxl/pandas)
9. **ریسپانسیو وب‌هوک‌ها** — اطلاع‌رسانی رویدادها (order placed, paid, shipped)
10. **اتوماسیون پس‌زمینه** — تسک‌های زمان‌بندی‌شده (به‌روزرسانی وضعیت مرسوله، یادآوری پرداخت سفارش‌های رهاشده)
11. **فاکتور PDF** — تولید فاکتور سفارش با reportlab/weasyprint
12. **درون‌ریزی/برون‌بری محصولات** — ابزار CLI یا ادمین برای import/export CSV محصولات
